# Drawing 1.2: identity systems and Retypo

Build a practical BI workspace for institutional identity systems: reusable
symbol, Korean/English vector-or-text logotypes, linked lockups, a matrix of
language/layout/tone combinations, clear-space/minimum-size rules, and a ZIP
delivery containing SVG assets and a manifest. Keep original SVG editing,
motion and open project compatibility. Persist identity data and mode.

Retypo: enumerate local TTF/OTF fonts through restricted Electron IPC, inspect
glyphs and Unicode coverage, compare vector outlines to glyph shapes, report
ranked candidates/confidence, permit correction, and replace approved outlines
with actual editable SVG text while preserving placement. Embed the chosen font
explicitly for portable projects. Geometry matching is not unrestricted OCR;
modified, overlapping or disconnected outlines must be reviewed.

Add contextual menus on canvas, objects, layers, inspector, inputs and timeline.
Keep text-field operations appropriate to input controls. Test synchronization,
undo, independent instances, generated variants and exported ZIP contents,
font reporting/matching/conversion, context menus and existing regressions.

Use feature commits and no-fast-forward merges. User has authorized autonomous
implementation through the EXE and waived skill approval gates in this session.
