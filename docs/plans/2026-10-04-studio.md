# Drawing 1.1 studio implementation

User intent: Illustrator-like SVG editing, multiple permanent examples, richer
strokes and Figma-like gradients, images and embedded fonts, an open project
format preserving the workspace, and simple keyframe motion. Existing request
authorizes implementation through Windows EXE without skill approval gates.

1. Public JSON `.drawing` format, versioned schema, SVG document, embedded assets,
   fonts, timeline and view state. Continue opening SVG and exporting SVG.
2. Strokes: cap, join, dash, offset and miter; linear/radial editable stops and
   handles; freeform point/line color fields rendered with SVG patterns.
3. Raster image embedding and full/subset font embedding with HarfBuzz WASM,
   retaining shaping closure. Explicit font character coverage and resource list.
4. Multiple editable examples, including gradients, typography and motion.
5. Separate design/motion workspaces. Object tracks, editable time/value/easing,
   scrub/play/loop, non-destructive preview and animated SVG export.
6. Integration, format validation, geometry/serialization checks, real Electron
   file roundtrips, UI tests and packaged Windows EXE smoke tests.

Use feature branches and frequent commits; integrate each with `git merge
--no-ff`. Ship source, open format documentation and portable Windows release.
