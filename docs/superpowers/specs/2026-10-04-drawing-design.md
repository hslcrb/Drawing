# Drawing 설계

작성일: 2026-10-04 (Asia/Seoul)

## 목적과 승인된 방향

Drawing은 SVG를 원본 문서로 사용하는 데스크톱 벡터 편집기다. 사용자는
일러스트레이터와 같은 편집 경험, 패스파인더, 색과 선이 없는 투명 요소의
선택 및 제거, Alt 복제를 요청했다. 앱과 공개 GitHub 저장소 이름은 Drawing이다.
사용자는 아래 기능 구성과 TypeScript + Electron 방향을 승인했다.

이 문서는 실제 구현과 검증의 기준이다. 기능은 버튼이나 목업을 만드는 것으로
완료되지 않는다. 문서 변경, 실행 취소, SVG 저장 및 다시 열기까지 동작해야 한다.

## 기술 선택

- TypeScript: 문서 명령과 편집 상태에 타입을 제공한다.
- Electron: Windows 데스크톱 창, 로컬 파일 열기 및 저장, 앱 패키징을 담당한다.
- React + Vite: 도구 모음, 속성 패널, 레이어 패널과 개발 빌드를 담당한다.
- SVG DOM: 화면 렌더링과 문서 직렬화의 원본이다. 캔버스 비트맵으로 대체하지 않는다.
- 벡터 기하 엔진: 곡선 기반 Boolean 연산을 제공하는 라이브러리를 검토하고 선택한다.
  선택 시 공식 문서, SVG 지원 범위, 라이선스와 실제 연산 테스트로 확인한다.

Kotlin + JavaFX는 JVM 데스크톱 배포에 적합하지만 SVG DOM 직접 편집을 위한
추가 계층이 필요하다. 웹 전용 구현은 SVG에 적합하지만 데스크톱 파일 작업과
배포가 별도다. Drawing은 SVG 직접 편집과 데스크톱 실행을 함께 제공한다.

## 화면 구성

- 상단: 새 문서, 열기, 저장, 내보내기, 실행 취소, 다시 실행 및 줌 표시.
- 왼쪽: 선택, 노드, 펜, 사각형, 타원, 선, 텍스트 및 손 도구.
- 중앙: 체크무늬 투명 배경 위 SVG 아트보드, 선택 테두리와 변형 핸들.
- 오른쪽: 위치·크기·회전, 채우기·선·선 두께·불투명도, 패스파인더, 레이어.
- 하단: 현재 도구, 선택 수, 작업 결과 및 오류 상태.

한국어 UI를 기본으로 하고 도구마다 이름과 단축키를 제공한다. 키보드 포커스가
텍스트 입력에 있을 때 편집기 단축키가 입력을 가로채지 않는다. 어두운 작업 영역과
밝은 아트보드로 문서 경계가 명확하게 보이게 한다.

## 문서와 모듈 경계

### SVG 문서

하나의 SVG 루트를 원본으로 유지한다. 객체는 고유 ID를 가진 SVG 요소다.
문서 크기는 width, height, viewBox로 저장한다. 도형, 경로, 텍스트, 그룹,
defs와 참조 관계를 보존한다. 편집용 선택 테두리, 핸들 및 안내선은 별도
오버레이 SVG에 표시하고 저장 결과에 포함하지 않는다.

레이어는 SVG g 요소로 표현한다. 이름, 잠금 등 편집기 메타데이터는 data 속성에
저장하며 다른 SVG 도구에서 일반 그룹으로 읽을 수 있어야 한다. 선택과 줌 같은
일시적인 UI 상태는 저장 문서와 분리한다.

### 명령과 기록

문서 변경은 하나의 명령 계층을 통과한다. 명령은 변경 전후의 SVG와 필요한
선택 상태를 기록한다. 드래그는 pointer-down에서 시작하여 pointer-up에서 한 번의
실행 취소 단위로 확정한다. 취소한 뒤 새 명령을 수행하면 다시 실행 기록을 비운다.
실패한 명령은 기존 문서를 유지한다. 저장 이후의 변경 여부로 수정 표시를 관리한다.

### 기하와 선택

SVG 좌표 변환, 경계 상자, 변형, 도형의 경로 변환과 Boolean 연산을 기하 모듈에
모은다. 화면 좌표는 viewBox 및 뷰포트 변환의 역행렬로 문서 좌표에 변환한다.
그룹과 중첩 transform이 있는 객체도 화면 위치가 유지되어야 한다.

### 파일과 데스크톱

Electron main은 파일 대화상자와 파일 I/O만 담당한다. renderer에는 Node 권한을
주지 않고 contextIsolation과 제한된 preload API를 사용한다. SVG를 열 때 XML을
검사하고 script, 이벤트 핸들러, 실행 가능한 URL 및 외부 실행 콘텐츠를 제거한다.
지원하지 않는 유효 SVG 표현은 가능한 한 그대로 보존하고 편집 가능 범위를 알린다.

## 기능과 동작

### 선택과 변형

클릭으로 객체 선택, 빈 영역 클릭으로 선택 해제, Shift 클릭으로 선택 토글,
드래그 영역으로 다중 선택한다. 잠긴 객체는 일반 선택에서 제외한다. 선택 객체는
이동, 크기 변경, 회전할 수 있다. Shift는 도형 및 크기 변경에서 비율을 유지하고
이동에서는 축을 제한한다. 속성 패널의 수치 입력은 동일한 명령을 사용한다.

Alt를 누른 채 선택 객체를 드래그하면 원본을 유지하고 복제본을 이동한다.
여러 객체의 상대 위치, 그룹 구조와 스타일을 보존하며 ID 충돌을 피한다.
복제 시작부터 이동 종료까지 한 번의 실행 취소로 돌아간다. Escape로 드래그를
취소할 수 있고 포인터가 화면 밖으로 나가도 pointer capture로 종료를 처리한다.

### 만들기와 노드 편집

사각형, 타원, 선은 드래그로 생성한다. 펜은 클릭으로 직선 앵커를 만들고 드래그로
곡선 핸들을 만든다. 첫 점 클릭으로 닫고 Enter로 열린 경로를 확정한다.
노드 도구는 앵커 및 곡선 핸들의 이동, 노드 추가 및 삭제, 경로 열기 및 닫기를
제공한다. 도형을 경로로 변환하여 노드 편집 및 패스파인더에 사용할 수 있다.
텍스트 도구는 위치를 선택하여 텍스트를 만들고 내용, 크기 및 글꼴을 편집한다.

### 스타일

채우기와 선을 각각 색 또는 none으로 지정한다. 선 두께, 전체 불투명도,
채우기 불투명도와 선 불투명도를 편집한다. none은 검정색이나 흰색과 구별한다.
문서 내 그라디언트 및 상속 스타일는 열기·저장 때 유지한다. 여러 객체를 선택하면
서로 다른 속성은 혼합 값으로 표시한다.

### 패스파인더

닫힌 도형 및 경로 두 개 이상을 대상으로 합치기(union), 빼기(subtract),
교차(intersect), 제외(exclude/XOR)를 제공한다. 빼기는 가장 아래 객체를 기준으로
위 객체들의 영역을 제거한다. 결과는 일반 SVG path 또는 복합 path로 저장한다.
색상과 선은 기준 객체에서 가져온다. 결과의 z-order는 기준 객체 위치를 사용한다.

중첩 transform은 문서 좌표에 반영하여 계산한다. 구멍과 복합 경로의 fill-rule을
반영한다. 빈 결과는 정상적인 결과로 처리하고 메시지를 표시한다. 텍스트와 이미지,
기하 엔진이 처리할 수 없는 효과는 조용히 버리지 않고 작업을 중단하여 설명한다.
연산 실패 시 선택 객체와 기존 SVG를 유지한다. 모든 연산은 실행 취소 가능하다.

### 완전히 투명한 요소 정리

사용자가 요청한 두 동작을 별도 제공한다.

1. 완전히 투명한 요소 선택: 검사 결과를 선택하고 개수와 이유를 표시한다.
2. 완전히 투명한 요소 삭제: 동일한 기준으로 검사하고 한 번의 명령으로 제거한다.

검사는 SVG의 기본값과 상속을 반영한다. fill 속성이 생략된 도형은 SVG 기본값인
검정 채우기가 있으므로 투명으로 판정하지 않는다. 다음 경우를 검사한다.

- 본인 또는 조상 opacity가 정확히 0인 그래픽 요소.
- 채우기와 선 모두 none인 도형·경로·텍스트.
- 유효 채우기 알파가 0이고 유효 선 알파도 0이거나 선 두께가 0인 요소.
- CSS transparent 및 알파 0 색 표현을 사용하는 채우기·선.

실제 화면에서 완전히 투명하다는 것을 증명할 수 없는 그라디언트, 패턴, 필터,
마스크 또는 외부 리소스는 삭제 대상으로 추정하지 않는다. stroke만 있는 선과
투명하지 않은 자손을 가진 그룹은 유지한다. visibility/display에 의한 숨김과
레이어 숨김은 색이 없는 투명 요소와 구분하여 이 정리 대상에 포함하지 않는다.

defs, clipPath, mask, pattern, marker, symbol 및 이들 내부 요소는 리소스이므로
직접 삭제하지 않는다. 다른 요소가 use 또는 URL로 참조하는 요소 역시 직접
삭제하지 않는다. opacity=0인 그룹을 삭제할 때 자손이 외부에서 참조되는지 검사한다.
검사와 삭제는 동일한 함수를 사용하고 삭제 직전 다시 검증한다. 미리보기 선택은
문서를 수정하지 않으며 삭제는 실행 취소로 완전히 복원한다.

### 공통 편집

잘라내기, 복사, 붙여넣기, 복제, 삭제, 모두 선택, 그룹, 그룹 해제, 앞·뒤 순서,
좌·중앙·우 및 위·중앙·아래 정렬, 수평·수직 간격 분배를 제공한다.
복사 시 SVG를 클립보드에 저장하며 붙여넣기 시 참조 ID를 다시 매핑한다.
레이어 패널은 순서, 이름, 선택, 숨김과 잠금을 제공한다.

Ctrl+Z/Shift+Ctrl+Z, Ctrl+C/X/V, Ctrl+D, Ctrl+A, Ctrl+G/Shift+Ctrl+G,
Delete, 화살표 이동 및 Shift+화살표 큰 이동을 지원한다. Space 드래그로 이동,
휠 확대·축소 및 화면 맞춤을 제공한다. 도구 단축키는 V, A, P, R, E, L, T, H다.
도움말에서 실제 구현된 단축키를 확인할 수 있어야 한다.

### 파일

새 문서 크기 설정, 로컬 SVG 열기, 기존 파일 저장, 다른 이름으로 저장 및 SVG
내보내기를 제공한다. SVG 파일은 일반 도구가 읽을 수 있는 XML이어야 한다.
열기 실패 시 현재 문서를 유지한다. 수정된 문서를 교체하거나 앱을 닫을 때
저장·버리기·취소를 선택할 수 있게 한다. 사용자가 내보낸 파일에는 편집 오버레이나
임시 선택 클래스가 포함되지 않는다.

## 검증과 완료 기준

- 문서 명령: 생성, 선택, 변형, 복제, 그룹, 정렬 및 기록의 결과와 복원을 테스트한다.
- 패스파인더: 겹친 도형, 서로 떨어진 도형, 구멍, 곡선, transform 및 빈 결과를
  면적·경계·출력 경로와 렌더 결과로 확인한다. 이름만 다른 동일 연산을 허용하지 않는다.
- 투명 정리: none/none, 기본 채우기, opacity=0, 상속, RGBA, stroke-only,
  숨김 레이어, 참조 리소스와 유효 자손을 가진 그룹을 각각 검증한다.
- 파일: 실제 SVG 저장 후 다시 열어서 기하와 스타일 및 문서 크기 보존을 확인한다.
- UI: 실제 브라우저 또는 Electron에서 드래그, Alt 복제, 노드 편집, 단축키,
  실행 취소와 파일 작업을 검증한다. 타입 검사, 자동 테스트 및 빌드를 통과한다.
- 배포: Windows에서 실행 가능한 Electron 패키지를 생성하고 실행을 확인한다.
  실행 방법과 지원 범위를 README에 기록한다.
- Git: .gitignore로 의존성·빌드·개인 환경 파일을 제외하고 기능 단위로 커밋한다.
  gh로 hslcrb/Drawing 공개 저장소를 생성하고 main을 푸시한 뒤 원격 상태를 확인한다.

## 진행 순서

이 설계 문서 승인 후 구체적인 구현 계획을 작성한다. 구현은 문서·기하 기반,
기본 화면과 도구, 고급 편집과 투명 정리, 파일·데스크톱 연결, 검증·배포 순으로
진행한다. 각 단계의 실패를 수정한 후 다음 단계로 이동한다.
