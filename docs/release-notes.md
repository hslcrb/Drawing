# Drawing 1.1.0

SVG 기반 디자인·모션 스튜디오로 확장했습니다. 기본 저장 형식은 공개 JSON
`.drawing`이며, SVG와 내장 리소스·작업 화면·키프레임을 함께 기록합니다.
기존 SVG 파일 열기와 SVG 내보내기도 유지합니다.

- 편집 가능한 내장 예제 5개와 예제 갤러리
- 스트로크 두께·끝 모양·모서리·대시·마이터·확대 시 두께 유지
- 선형·방사형·자유형 점/선 그라데이션, 스톱·알파·좌표와 캔버스 핸들
- SVG 텍스트, PNG/JPEG/WebP/GIF 이미지 포함, TTF/OTF 글꼴 전체/사용 글리프 포함
- 디자인·모션 모드, 이동·회전·크기·불투명도 키프레임과 재생·반복·보간
- 정적 SVG 및 JavaScript가 필요 없는 애니메이션 SVG 내보내기
- 공개 포맷 명세와 JSON Schema, 화면 복원, 리소스·모션 편집 실행 취소

자유형은 SVG 색상 필드 합성 방식입니다. 부분 포함 글꼴에 새로운 문자가 필요하면
폰트를 다시 포함하세요. 프로젝트로 저장하면 편집 가능한 모션을 보존합니다.

`Drawing-1.1.0-win-x64.exe`는 Windows x64 포터블 앱입니다. 설치와 Java 런타임이
필요 없습니다. 로컬 Chromium·Electron 테스트와 실제 EXE 검증을 수행했습니다.
실행 파일은 코드 서명되지 않았으며 SHA256SUMS.txt로 파일을 확인할 수 있습니다.
