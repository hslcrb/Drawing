# Drawing 1.0.2

실행하면 “Make something wonderfully yours.” 예제 문서가 바로 열립니다.
상단 **예제** 버튼으로 언제든 원본 예제를 다시 열 수 있습니다. 예제 SVG는 앱에
포함되어 별도 파일이 필요 없으며, **새 문서**는 계속 빈 아트보드를 만듭니다.
수정 중인 문서는 저장 여부를 확인하고, 예제 저장은 이전 파일을 덮어쓰지 않도록
새 저장 위치를 선택합니다.

- 펜·도형·텍스트와 앵커·곡선 핸들 편집
- 합치기·빼기·교차·제외 패스파인더
- 완전히 투명한 요소 선택·삭제와 안전한 리소스 보존
- Alt 드래그 복제, 그룹·정렬·레이어, 클립보드와 실행 취소
- 로컬 SVG 열기·저장·내보내기

`Drawing-1.0.2-win-x64.exe`는 설치 없이 실행하는 포터블 앱입니다. Java 런타임은
필요하지 않습니다. Windows 코드 서명은 적용하지 않았습니다.

로컬 Chromium·Electron 자동 테스트와 실제 포터블 EXE 실행 검증을 수행했습니다.
GitHub Actions는 계정 결제 문제로 실행이 차단되어 있어 로컬 검증 결과를 제공합니다.

세부 기능, 단축키와 지원 범위는 README를 참고하세요. `SHA256SUMS.txt`에서 다운로드한
실행 파일의 해시를 확인할 수 있습니다.
