# Drawing Identity Studio and Retypo

## 상징체계

상단 **상징체계**에서 심볼·국문 로고타입·영문 로고타입을 원본 컴포넌트로
등록합니다. 원본은 일반 SVG 경로, 그룹 또는 텍스트이며 기존 디자인 도구로
편집합니다. 여러 요소로 구성된 심볼은 먼저 그룹으로 묶으세요.

국문·영문 명칭을 입력하고 **국문·영문 텍스트 준비**를 누르면 텍스트 원본을
만듭니다. 기존에 등록한 로고타입은 덮어쓰지 않습니다. 준비한 텍스트는
명칭 변경과 연결됩니다. 직접 등록한 텍스트나 경로는 원본 편집으로 수정합니다.

매트릭스는 국문/영문/국영문, 가로형/세로형/로고타입/심볼, 기본색/보조색/
단색/반전색을 조합합니다. 기본 선택은 36개이며 생성은 프로젝트당 500개까지입니다.
기존 작품 아래에 조합을 배치하고 아트보드를 확장합니다. 조합 목록을 클릭하면
해당 조합으로 확대·이동합니다. 보호 공간과 이름은 캔버스 안내이며 ZIP의 SVG에는
포함하지 않습니다. 최소 사용 너비는 전달 규정으로 manifest와 README에 기록합니다.

원본을 수정하면 `<symbol>` 정의와 `<use>` 인스턴스가 갱신됩니다. 조합에서
Alt 드래그 또는 복제를 해도 연결을 유지합니다. **연결 해제**는 현재 원본과
색을 일반 SVG 객체로 풀어 개별 편집하게 합니다. 이후 원본·팔레트 변경의
영향을 받지 않습니다. 삭제한 원본은 정의가 남아 있으므로 원본 편집으로 복구합니다.

ZIP은 언어/배치별 SVG 파일과 `identity-manifest.json`, 사용 규정 README를
포함합니다. 각 SVG는 자체 정의를 포함해 독립적으로 렌더링됩니다. 반전형은
기본 브랜드 색의 배경을 포함합니다. 화면 안내와 조합 이름은 제외합니다.
일반 프로젝트 저장은 원본·조합·리소스·현재 모드를 함께 보존합니다.

## Retypo

우클릭 메뉴 또는 상징체계 패널에서 **Retypo**를 엽니다. Windows의 시스템 및
사용자 TTF/OTF 폰트, 프로젝트 내장 폰트, 직접 연 폰트를 선택할 수 있습니다.
글리프 수·Unicode 문자 수·UPM과 실제 글리프 윤곽을 조회하고 문자나 U+코드로
검색합니다. 글리프를 누르면 비교 문자 집합에 추가합니다.

경로로 된 글자 또는 그룹을 선택하고 비교 문자 집합을 지정한 뒤 **선택 경로
분석**을 누르세요. 빈 비교 집합은 선택 폰트의 처음 4,096문자를 비교합니다.
문자당 상위 5개 후보와 평균 형태 유사도를 표시합니다. 이는 인식 확률이 아닙니다.
선택한 폰트의 윤곽을 비교하는 기능으로, 임의의 모든 폰트를 자동으로 판별하는
OCR은 아닙니다. 심하게 변형되거나 겹친 글자와 줄바꿈은 문구를 직접 보정하세요.

결과를 확인하고 **편집 가능한 텍스트로 복원**하면 실제 `<text>` 객체로 바뀝니다.
기존 위치·회전과 전체 경계 상자를 맞추고 채우기·선을 가져옵니다. 원본 하나의
ID와 컴포넌트 역할을 유지하며 실행 취소가 가능합니다. 선택 폰트 전체를 프로젝트와
SVG에 포함하므로 재열기 및 추가 문자 편집이 가능합니다. 폰트의 임베딩 권한은
해당 라이선스를 따릅니다. TTF/OTF를 지원하며 TTC 컬렉션은 지원하지 않습니다.

**문구를 글리프 경로로 삽입**은 폰트의 실제 글자 윤곽을 일반 SVG 경로로 만듭니다.
따라서 글리프를 심볼·로고타입의 출발점으로 쓰거나 Retypo 복원을 시험할 수 있습니다.

## 우클릭

캔버스·객체·레이어·속성 패널·상단·타임라인에서 빠른 작업 메뉴를 제공합니다.
객체나 레이어를 우클릭하면 해당 객체를 선택하며 이미 선택한 복수 객체는 유지합니다.
입력란에서는 입력 복사/잘라내기/붙여넣기/전체 선택을 제공합니다.
Escape로 닫고 방향키로 메뉴를 이동할 수 있습니다.
